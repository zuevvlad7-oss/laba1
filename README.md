Учебный скрипт на Python, который определяет текущую ОС, собирает параметры внутри нее и записывает результат в JSON-файл.
Для чего необходим?
1) Определяет, на какой ОС запущен код (Linux, macOS, Windows)
2) Собирает набор параметров про ОС, железо и окружение Python
3) Сохраняет все в файле JSON
4) Печатает то же самое в консоль.
Для запуска необходимо иметь Python версии 3.6 или новее. Внешние библиотеки не требуются.
#Собираемые параметры:
1. Название системы (platform.system())
2. Версия релиза/ядра (platform.release())
3. Подробная версия ОС (platform.version())
4. Архитектура процессора (platform.machine())
5. Имя текущего пользователя (getpass.getuser())
6. Домашняя директория (os.path.expanduser("~"))
7. Текущая рабочая директория (os.getcwd())
8. Модель процессора (platform.processor())
9. Количество логических ядер (os.cpu_count())
10. Имя компьютера в сети (socket.gethostname())
11. IP-адрес (socket.gethostbyname())
12. Общий объем диска в ГБ (shutil.disk_usage())
13. Занято на диске в ГБ (shutil.disk_usage())
14. Свободно на диске в ГБ (shutil.disk_usage())
